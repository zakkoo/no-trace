# mytool-tailsworkflow

Sets up and verifies the BitBoxApp in Tails Persistent Storage.

- Download *wizard.sh* into *~/Persistent/wizard.sh* 
- Open the terminal and enter following commands.

```
cd ~/Persistent
chmod +x wizard.sh
./wizard.sh
```

- Go through the wizard step by step and make sure to read every instruction carefuly!
- Good luck!
